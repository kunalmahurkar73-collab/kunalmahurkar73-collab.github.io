# Amazon checkout prototype

Independent educational React/TypeScript simulation. The built site is published at `/amazon-checkout-prototype/` on the same GitHub Pages domain as the portfolio. It uses fictional sample addresses and local browser state; no real Amazon account or payment is connected.

## Rebuild

Run `npm ci` and `npm run build` in this directory. Copy the contents of `dist/` into the repository's `amazon-checkout-prototype/` directory. The Vite base path is fixed to that public route. Commit the source and generated files together in a feature branch.

The screenshot evidence and heuristic analysis live in `../case-amazon-checkout.html` and `../evidence/`.
