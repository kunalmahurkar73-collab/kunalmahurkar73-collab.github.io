# How India Plans & Books Its Trips

Independent research by Kunal Mahurkar. Estimated duration: 3–4 minutes; the timing has not yet been validated with participants. Anonymous by default. Not an Airbnb survey. Real survey data is separate from synthetic demonstration data.

## Consent and branching

Participants confirm they are 18+, live in India and consent to anonymous research use. Role choice branches to traveller or host questions. People who do both choose one perspective. All single-choice questions are required; multiple selections and open feedback are optional. City is a broad list with an Other India city/town option. The form requests no contact information. Interview volunteering happens separately through the portfolio contact link after submission, with no survey-ID linkage.

## Traveller path

1. Age group: 18–24 / 25–34 / 35–44 / 45–54 / 55+.
2. Current city: Mumbai / Pune / Bengaluru / Delhi NCR / Hyderabad / Ahmedabad / Chennai / Kolkata / Jaipur / Kochi / Other India city or town.
3. Domestic overnight leisure trips in the past 12 months: 0 / 1 / 2–4 / 5+.
4. Most recent accommodation booking: Booked Airbnb / Booked hotel or OTA / Browsed Airbnb, never booked / Someone else booked / No accommodation booking in past year.
5. Platforms used in the past year, multiple choice: Airbnb / MakeMyTrip / Booking.com / Agoda / StayVista / Direct hotel or host / Other / None.
6. Usual duration: 1 night / 2–3 / 4–6 / 7+ / Not applicable.
7. Usual travel group: Solo / 2 people / 3–4 / 5–6 / 7+.
8. Accommodation budget per person per night: Under ₹1,500 / ₹1,500–2,999 / ₹3,000–4,999 / ₹5,000+ / Varies or not sure.
9. Difficulties on the most recent trip, optional multiple choice: Group trip coordination / Trust and property reliability / Budget disagreements / Total booking cost / Finding suitable dates / Local activity discovery / None.
10. Total cost clarity before booking: Very clear / Somewhat clear / Neither / Somewhat unclear / Very unclear / Did not book.
11. Main reason for a recent unfinished booking: Did not abandon / Total cost / Could not agree with group / Property uncertainty / Dates unavailable / Payment difficulty / Changed plans / Other.
12. Considering the previous platform when planning again: Always / Often / Sometimes / Rarely / Never / Have not booked before.
13. Finding local activities on latest trip: Friends or family / Search or maps / Social media / Accommodation platform / Host recommendation / Did not look.
14. Usefulness of shared date, budget and property comparison: Very useful / Somewhat useful / Neutral / Not very useful / Not useful.
15. Usefulness of reusing a previous group and preferences: same five-point scale.
16. Usefulness of optional activities after booking: same five-point scale.
17. Optional open feedback, maximum 1,200 characters; do not enter personal details.

## Host path

1. Property city: same broad city list.
2. Property type: Entire apartment / Villa / Private room / Homestay / Hotel or guesthouse / Other.
3. Hosting experience: Not yet hosting / Under 1 year / 1–3 years / 4+ years.
4. Largest occupancy challenge: Weekday gaps / Seasonal demand / Low discovery / Last-minute cancellations / No significant challenge / Other.
5. Guest expectations hardest to meet, optional multiple choice: Accurate property details / Cleanliness / Wi-Fi or workspace / Kitchen / Check-in flexibility / Group space / None.
6. Main pricing challenge: Seasonal decisions / Competitor comparison / Communicating total cost / Discount expectations / No significant challenge / Other.
7. Requested group requirements, optional multiple choice: Shared dining / Enough beds / Parking / Multiple bathrooms / Flexible arrival / Child-friendly amenities / Not sure.
8. Group readiness: Fully prepared / Mostly prepared / Improvements needed / Not suitable / Not sure.
9. Operational challenges, optional multiple choice: Cleaning / Communication / Maintenance / Cancellations / Check-in / None.
10. Usefulness of explanations of potential listing improvements: five-point usefulness scale.
11. Needed before acting on a recommendation: Evidence of demand / Cost estimate / Clear explanation / Ability to dismiss / Would not use / Other.
12. Optional open feedback, maximum 1,200 characters.

## Method and limitations

Behaviour questions precede proposed-feature questions to reduce priming. Usefulness is stated preference, not evidence of adoption or willingness to pay. No proposed feature is called a solution in the questionnaire. A convenience sample from a portfolio can overrepresent urban, digitally experienced respondents; do not generalize it to India. Random sampling and validated measurement scales are not implemented. The feature descriptions should be reassessed in a neutral pilot interview before broad distribution.
