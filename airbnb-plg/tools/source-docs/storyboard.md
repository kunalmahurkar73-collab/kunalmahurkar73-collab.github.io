## Recording checklist

- Use only sample data. Close personal-account tabs, email, chats and notifications.
- Keep the simulation labels visible. Do not record a real booking or send invitations.
- Use the presentation script and rehearse transitions before recording.
- Record desktop at 1920 × 1080 if available. Increase browser zoom enough for readable labels.
- Include captions or a transcript. Check audio and screen legibility before upload.
- Upload only a finished recording to an approved destination. This project currently includes no video file or video link.
- Test the uploaded link in a signed-out browser before adding it to the portfolio.
